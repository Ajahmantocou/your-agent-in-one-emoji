One emoji that stands for an AI agent: **🦾 Mechanical Arm** (U+1F9BE).

## Why this emoji

An agent is not defined by having a face or by merely thinking — it is defined
by what it *does*. The mechanical arm is the working limb itself: the part of
the agent that reaches into the world on your behalf, picks up tools, and
finishes the job while you watch. It says "acting for you" at a glance, its
shape stays clear and familiar at small size, and it is specific about how an
agent works — tool use, execution, doing — instead of the obvious robot head
🤖 or smiley 😊 that half the field sends. Serious about the work, playful in
tone, and it lands with no explanation at all.

## Run it

```sh
node main.ts
```

This writes the single emoji to `/output/entry.txt` (deterministic — every run
produces the exact same bytes).
